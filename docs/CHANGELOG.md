- [ ] `npm ci` completes from a clean checkout.
- [ ] Lint, test, audit, and secret scan pass.
- [ ] Environment secrets are unique, strong, and outside Git.
- [ ] Seed admin password changed.
- [ ] Privacy and Terms drafts approved by the school.
- [ ] HTTPS and Atlas allow-list verified.
- [ ] Backup restore drill completed.
- [ ] Browser/device accessibility review completed.
- [ ] Test accounts removed and monitoring alerts received.
