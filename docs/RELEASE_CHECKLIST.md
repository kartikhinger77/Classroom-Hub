# Release checklist

- [ ] Clean `npm ci`, lint, tests, npm audit, and secret scan pass.
- [ ] Required environment values are set and unique secrets generated.
- [ ] Production MongoDB uses a least-privilege account and a narrow IP allow-list.
- [ ] HTTPS, HSTS, origin, SMTP, and DNS are verified.
- [ ] Seeded admin changed its account password.
- [ ] Privacy and Terms drafts are approved by the school.
- [ ] Student self sign-up decision is recorded.
- [ ] Logo uploaded and all pages checked at mobile and desktop sizes.
- [ ] PDF scanner decision and private upload storage backup are documented.
- [ ] Daily encrypted backups run and a restore has been tested.
- [ ] Monitoring alert routes are verified.
- [ ] Test accounts removed and role-by-role walkthrough completed.
