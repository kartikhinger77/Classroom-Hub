TEACHER GUIDE

Share class material

Upload a PDF

Choose Notes or Exercise. Select Create a post. Enter a title and subject. Choose a PDF under 10 MB. Publish the post.

Write a post

Choose Create a post. Enter a title, subject, and type. Write in the content box and publish. The site removes unsafe formatting.

Edit or delete

Open your post. Choose Edit to update it. Choose Delete to move it to Trash. You can view and restore one of the last ten written versions while editing.

If an upload fails

Check that the file opens as a PDF and is under 10 MB. Try again when your network is stable. Ask an admin if the problem continues.
