ADMIN GUIDE

Manage the school site

Accounts

Open Admin and choose Users. Add an account and share its temporary password privately. Use Suspend, Reactivate, Reset password, or Remove as needed. You cannot remove yourself or the last admin.

Subjects and announcements

Use Subjects to add or deactivate subjects. Posts need an active subject. In Settings, control Student self sign-up and set the announcement dates.

Audit log

Open Audit log to review admin actions, times, and IP addresses. Opening the log is recorded too.

Forgotten admin password

Use the server-only `npm run recover-admin` procedure in the private operations guide. The website has no password bypass.
